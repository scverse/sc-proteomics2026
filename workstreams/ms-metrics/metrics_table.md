| Imputation preserves local structure  | For imputation — preserve local structure of data as per `computeStructuralMetrics` ([msImpute manual](https://bioconductor.org/packages/release/bioc/manuals/msImpute/man/msImpute.pdf)); requires knowledge of sample metadata, i.e. which sample belongs to which group. They compute Gromov-Wasserstein distance (GW) on the PCs before and after (recommend to do the PCA on highly variable peptides; found like this: a loess trend is fitted to total sample variances and mean intensities. For each peptide, the biological variance is then computed by subtracting the estimated technical variance from the loess fit from the total sample variance.) | Log intensity matrix + sample metadata | Batch                                   | Rewards conservatism (pre-imputation structure treated as ground truth); unstable on small datasets                                | Imputation              | Real world |
| Imputation preserves feature variance | Quantify the change in variance in each feature before/after imputation; good imputation / imputation on features that are not too missing should not drastically inflate/reduce feature variance                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | AnnData (before and after imputation)  | No                                      | Problematic case MNAR with many missing values: would be expected to increase variance, so interpretation is not 1/0.              | Imputation              | Real world |
| Point cluster distance                | Should capture the relationship between cells using pairwise distances. O(N²) complexity, therefore estimated by PCD: get clusterings, compute centroids, get pairwise Euclidean distances between cells and clusters.                                                                                                                                                                                                                                                                                                                                                                                                                                              | Before/after matrices                  | No                                      | Depends on clustering method (now: Leiden); rewards conservatism (pre-processing state treated as ground truth)                    | All steps               | Real world |
| Neighborhood preservation             | What percentage of neighborhoods overlap between KNN graphs before/after preprocessing step. Caveat: "redundancy" as every cell is part of k other neighborhoods. The idea of this metric is that imputation should likely not fundamentally change the neighborhood structure of a cell population. This metric identifies all neighbors of a cell before imputation and after imputation and computes the Jaccard similarity of the neighbors.                                                                                                                                                                                                                    | KNN graph                              | No                                      | Rewards conservatism (doing nothing scores perfectly); k-sensitive (small k noisy, large k washes out local structure)             | Imputation              | Real world |
